# 横梁截面转90°与既有连接的安装面对应

## 来源与确认范围

用户在纠正“生成在正面，我要侧面内收的梁外面部分”后询问“横梁不是也可以转90度那种方式安装吗”，本轮明确“确认，这种也要支持的”。本版补沿横梁自身长度轴的截面整90°转动，以及对应的既有目录设计连接；不把转梁解释为交换宽深、整架转向或自动更换全部角码型号。

此前提供的JSON和用户真实浏览器草稿不直接修改。本轮依据当前源码工作，不导入用户工程，不执行浏览器/HTTP、测试、语法检查、Java编译或服务启动/重启。v62的内收侧梁外侧角和原梁下连接继续存在，不能重新改成正面板。

## 操作入口与边界

- 单独选择一根水平直型材，作用域为“单个构件”时，原旋转弹层增加“截面 +90°”。围绕该构件局部Z长轴转动，不受画布轴 / 构件轴开关影响，两个梁端不移动；3030换槽面，3060切换立放 / 平放。按钮可连续点击，弹层不自动收起，不增加常驻第二排。
- XYZ +90°和原快捷键仍走原方向 / 作用域 / 主选中心规则。普通拖动旋转Gizmo、XYZ按钮以及右侧角度输入若实际形成原地长轴整90°转动，也进入同一局部安装面对应链；不能根据按钮名称推断转截面。
- 有效锁定、已安装配件、非水平 / 非直杆、非单选 / 非SINGLE、负缩放或非单位缩放不提供截面入口。明确的截面转动若被约束投影成其他角度或平移，恢复原姿态并提示，未提交连接 / 历史；不能用“旋转成功”掩盖约束拒绝。
- 旋转前临时矩阵快照只服务本次操作；不写Project、Schema或草稿。提交仍是原Editor事务，取消未重映射，确认一次历史 / 工程提交，撤销走原快照。

## 安装面与局部参考

ProfileRollConnection仅识别两个姿态都为单位正缩放、同中心、同向水平长度轴且相对角为整90°倍数的直型材。旧局部面法向经旧世界姿态 / 新局部姿态找到新的FRONT/BACK/LEFT/RIGHT；映射保持世界安装侧，不把梁下角码跟着梁转到梁上。

- 普通梁端 / 两梁内角连接的sourceMountFace、单件安装面和targetFace按受转宿主对应；源端面designAnchorOffset随局部XY坐标变换，非零多槽偏置不归零。sourceEnd和宿主ID不变。
- SIDE_MOUNT梁下参考件和OUTER_CORNER外侧原生件分别保持原身份 / mode / 源站位，sourceContactFace、targetContactFace和源槽横向偏移对应新局部面。不会把梁下角码改成外侧角码或移动到另一根柱。
- SIDE_SLOT仅沿已映射两孔一字板的源面与双方槽横向偏移对应；不扩展普通平板、台阶板或未知多孔安装。
- 只对已有映射的ANGLE_BRACKET / CORNER_CUBE / L_BRACKET / HIDDEN_CORNER及SIDE_SLOT原生两孔板做实际设计件对应。制造方案、抽象端面 / 锚式、未知组件或遗留多侧合并记录不自动改制造孔组或假报已重安装。
- 原连接ID、具体型号、全部尺寸、人工 / 自动状态和其他方向的独立连接保持。已存型号记忆同步局部面 / 偏置参考，切回时仍要重新检查，不能恢复旧面或把原几何换成简化板。

## 真实适配检查

所有相关连接先统一对应并重建，再按原ConnectionPlacementManager评估本件，忽略项只有本连接自身。源 / 目标真实开放槽、孔轴0.15mm、贴合0.1mm、完整两腿 / 槽腔、其他构件和全部实际新连接helper继续检查；不能因还显示转动前的helper误挡，也不能暂时隐藏另一件漏查碰撞。

只有局部面名称变了而实际世界安装不变的3030等案例可保留原安装位置；3060立平互换后若真实接触面移动、孔槽中心变化、完整支撑不足或与柱 / 板 / 其他件穿透，原规格不会自动改孔、缩腿或平移宿主凑装。保存新的局部安装意图，但连接标INVALID、去掉错误实体并显示原因；记录 / 编号不按“单个移动解除”规则删除，下一次截面转动仍可按当前意图继续对应。

新生成 / 手动安装仍使用原真实面候选。快捷搭建六部位的90°朝向和v3真实槽对布局保持；不将单根手工转动反写为整类梁的统一参数，不自动重建其他梁。AUTO普通角码 / 隐藏件与每层承托面留平、制造门禁保持。
