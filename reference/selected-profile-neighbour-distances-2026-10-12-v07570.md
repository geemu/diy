# 单选型材的长度 / 同框面最近邻距 — v0.75.70

## 来源与已确认范围

用户提供嘉立创截图：单选一根型材，周围有长度和400 / 260 / 30 / 580mm等距离输入，Tab可切换不同输入。确认实现此前说明的方案：单选临时显示，长度与距离带对应箭头，输入最终净距，只移动所选杆，固定A/B端沿原规则，保留锁定/约束/连接/干涉/历史保护。

截图是交互参考，不是参考站的距离算法或可复制代码。只读当前仓库实现，未采集对方代码、改用户桌面JSON、真实Chrome/localStorage或运行当前工程。本版不以截图示例数值硬编码关系，不宣称参考站全部功能/口径或制造精度一致。

## 领域事实与参照

- ProfileNeighbourDistances读取已知T_SLOT的业务截面尺寸、直杆长度及当前本体世界姿态；共用ProfileFeatureCatalog.profileSidePlanes和PartCollisionDetector.profileObb / sweepObbContact，不从显示标签、圆孔、轮廓辅助网格或相机投影猜尺寸。
- 只支持方切 / 单位缩放 / 世界正交的邻距。四侧面的全部角点至另一平面偏差≤0.1mm才同框面，测量方向须平行共同面；平行杆只认同向外面，排除上下接触而实际属于另一层，垂直杆允许框侧面相向。投影在剩余方向不交叠时，不给沿该轴的假参照。
- 每个世界±X/Y/Z只取最近的一根明确ID，共最多六个净距。口径为原截面外包络的轴向间隙，不是中心距/沿型材槽空腔的精确B-Rep距离；既有原孔或加工不会把此包络偷偷变小。每次模型变更重新求最近，提交前还检查显示时的参照/位置是否过期。
- 长度符合原直杆路径即可按原抓手规则显示，邻距未适配的型号/方向不外推。已选一根但锁定、或长度移动端受原连接/约束时，相关输入只读。

## 显示与输入

- SelectedProfileDistanceManager的DOM和临时Scene组不加入Editor.meshes / 选择拾取 / 模型包围盒 / Project / 永久Dimensions / BOM / 工程图。显示端点取实际包络面，整条尺寸线/延长线/小箭头随标签一起避让，不仅移动数值。
- 长度框先于邻距，有限屏幕档位避开所选主体包络和已有尺寸标签；背向、其他实际型材/板材/五金遮挡、出视口或空位不足不硬塞，隐藏项不进Tab循环。临时线保留实体深度测试，不以无视材料的覆盖线强行宣称孔槽可见。
- Tab / Shift+Tab循环可见可编辑框，Enter提交最终毫米值；Esc只撤当前未提交草稿并返回画布焦点，不清选择。切框不自动提交，成功变更后刷新本组数值；未提交输入用小点提示。其他按钮/表单原Tab正常，输入Ctrl文字剪贴板/方向键及Ctrl/Meta/Alt+Tab不用于构件操作。
- 默认Math.round整毫米展示，仅改变文本。明确输入小数可提交，未输入就Enter不把原值取整；空文本/非有限值/负距/非法长度显示原因，锁定不能绕过。固定A/B端与右侧长度表单同步，默认原A端。
- 多选、绘制/放置/安装、评审、抓手/Gizmo拖动、标尺/永久尺寸/框选/特征、播放/爆炸、模态不启用；原底栏相对移动量及这些工具的Tab优先级不变。换选/工具/工程变化、新建/导入/清空/卸载不保留过期输入。

## 修改、约束和事务

- 例如净距260→200，沿参照方向移动60，参照和其他型材固定。命令用世界测量方向单根移动，临时使用translate / SINGLE，不更改用户当前工具、世界/局部轴和移动作用域偏好；不偷偷移动整个组件或连接网络。
- 包装原Gizmo / moveSelectionToSurface路径，禁用本次数值提交的自动拉向另一接头；原两阶段约束解算后重查所选完整位置、全部型材朝向、其他型材位置及最终指定参照净距，不满足就拒绝还原。检查在连接/历史提交之前，不能松约束或移动参照凑输入值。
- 原连接更新、SINGLE失效接头解除和提示、附件随宿主保留；其他实体干涉仍为红色并保留既定位置，不改变项目既有“允许继续调整”的策略。正确净距不等于无干涉、实体安装或承载验收。
- 长度复用ProfileGripEditor固定A/B端、移动端保护和加工基准调整，不新增第二长度算法。成功一次历史/工程提交，失败用原工程/历史/选择快照恢复；selectionGraphMutation阻止半次编辑写草稿，只看/Tab/Esc/输入文本不提交。
- 工程变更才重算领域候选/DOM/材料，镜头仅投影和实际遮挡重查；每条线固定BufferGeometry、顶点不同才上传，清理时释放。不以缓存实现宣称实际帧率或内存已测。
