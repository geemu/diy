# Lewan 型材绘制公开观察 — 2026-10-07 / DIY v0.75.17

来源：[LewanDIY公开编辑器](https://www.lewandiy.com/editor)，隔离匿名Chrome会话，页面标注v2.0.0。仅正常UI/DOM/截图观察，不读取第三方应用源码或私有运行对象，不登录、不使用PRO、不保存第三方工程。

## 实际观察

- 创建 → 铝材 → 点击出料口预览：进入绘制画笔状态，首击前指针附近是一小段截面真实型材，不是完整默认长料；顶部提示Tab切换方向。
- 实际canvas光标为固定屏幕大小的橙色环/十字/中心点瞄准器，而非普通箭头或世界尺寸球。截图无法捕获操作系统光标，DOM计算cursor确认其存在；没有复制专有模型资源。
- 第一击后显示“铝型材长度 (mm)”与“Enter 确认 · 点击确定”；输入框为空、占位“输入长度”、自动聚焦。鼠标移动改变待确认型材的长度。
- 第二击后长度框消失，右侧显示所选新构件属性（P-13；观察到的长度示例910/907mm），不自动跟出另一根固定长度构件。
- 已有公开示例框架的局部接头呈黄色带，与正在选择/操作状态分开。此观察只能支持颜色/公开行为，不能推断其私有吸附或碰撞算法。

## 本地实现与边界

- 普通点击预览和拖到画布统一拿起FREE画笔，首次只定起点、第二次或数值才生成一根；首击前40–120mm短段是独立展示尺度，不是测得的供应商制造参数。
- 固定32px橙色瞄准光标用通用SVG几何独立构造；未确认实体只在渲染层，不写Project/BOM/历史/localStorage。长度框保持紧凑，不恢复遮挡画布的大提示卡。
- 接头黄色来自实际接触面裁剪，候选绿、干涉红优先和齐平紫保留；几何贴合不意味着真实五金已生成，制造门禁不改变。
- 内部固定放置API保留，但不占普通绘制入口。未观察/未验收的登录、PRO、全目录和复杂流程继续列于ROADMAP，不能将本轮修复宣称为完整一比一复刻。
