# 基础搭建公开观察与取舍 — 2026-10-08 / v0.75.18

## 观察方式与范围

- 普通隔离 Chrome / Playwright 匿名会话访问 [Lewan 编辑器](https://www.lewandiy.com/editor) 和 [嘉立创自由设计器](https://xc.jlcfa.com/free-design)。本轮普通浏览器可加载嘉立创 iframe `profile-editor?iframeId=freeDesignEditor`，不沿用早期工具读取失败作为当前不可访问结论。
- 未登录、未使用用户凭据、未保存第三方设计、未付款或绕过 PRO；未抓取复制对方专有源码/网格。观察 UI 结果与本地实现推断分开。

## Lewan 实际看见的行为

- v2.0.0 默认示例含12根型材，点组内构件会整体选择；E 可打开快速对齐选项。
- 可见垂直连接90°、统一长度/两端对齐、端面对齐、中心 X/Y/Z 复选方向、均分排列和黄金比例排列。12件选择下垂直连接禁用。
- 尝试解组与多选未建立两件独立选择，因此本轮**未实际执行参考90°结果**，不声明复刻了其具体锚点/自动转向内部算法。公开菜单及已有几何规则作为独立实现的交互依据。

## 嘉立创实际看见的行为

- 左侧可见自由绘制、斜角、单根、矩形、箱体。点击自由绘制、首击并移动得到真实型材及跟随的就地毫米输入；输入500并回车后右侧列表成为一根，结果与输入一致。
- 编辑连接件页可见一键生成、默认角码/修改、按指示区域安装及退出；说明可能附带附件和孔位。进入时主体临时半透明、锁定，安装操作与主体编辑分开。
- 会话仅生成一根型材，**没有实际执行可用接头的批量五金/孔位生成**。不可从页面说明推断其算法、精确制造图或所有规则；本地不照抄这一制造承诺。

## 本地问题与 v0.75.18 独立实现

1. 长度输入：回到起点时0长度清理会隐藏输入，清空数值未及时恢复鼠标 Ghost；现修正输入生命周期，不恢复默认500mm连续添加。
2. 快速对齐：原入口立即执行、基准与端点不清楚、中心单轴、90°缺失；采用右侧固定基准/复选轴/A-B端审阅，目标模型青色/干涉红色。90°使用已有真实法向、ProfileOrientation、Snap完整截面足迹，不凭屏幕投影对齐。
3. 整体连接：原批量创建抽象关系不能等同具体目录五金；采用扫描→目录组件黄透明预览→勾选→一次提交。共用既有放置/安装守卫与模型，已有关系保留，未贴合说明毫米间隙，不偷偷移动型材。
4. 保护与取消：主体不变、相机可转、背景编辑隔离，取消不写草稿；确认走已有Manager/历史/localStorage，原制造门禁不放宽。设计组件不是配套螺钉/孔位已生成。
