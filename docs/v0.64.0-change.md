# v0.64.0 变更说明

## 目标

面向不会 CAD 的玩家补齐“先搭结构、再一键补连接、必要时安全重来”的基础闭环，并把项目对外名称同步为 DIY。

## 玩家连接闭环

### 扫描整个结构并补全连接

连接页和编辑菜单新增显式扫描入口。该操作：

- 扫描当前工程全部 PROFILE；
- 复用 SnapManager 的几何候选；
- 复用 AutoConnectionResolver 的候选折叠和端点占用规则；
- 复用 ConnectionManager 创建抽象设计连接；
- 不移动构件；
- 不覆盖已有连接；
- 不提前绑定真实角码、螺钉或加工规则；
- 即使“新建构件自动连接”关闭，也会按用户明确操作执行。

### 清除纯自动连接

清理入口只删除仍标记为 autoGenerated=true 的连接。手工创建连接和已经人工切换过连接方式的关系不会被删除。删除继续逐条经过 ConnectionManager.removeConnection()，从而同步清理连接派生的五金、加工和场景 Helper。

### 连接状态总览

连接页显示：

- 全部连接；
- 纯自动；
- 手工 / 已改；
- 几何失效。

这些数字由当前 connections 即时派生，不写入 Project JSON。

连接安装说明继续复用 `ConnectionInstallationDiagram`，当前图卡同时展示安装步骤和“3 → 2 → 1”反向拆卸顺序。

## 项目改名边界

- 页面品牌：DIY 铝型材设计器；
- Maven artifact：diy；
- Spring application name：diy；
- 新工程 generator：DIY Web；
- Java 包名继续使用 com.paic.stock.aluminumcad；
- SQLite 文件继续使用 ./data/aluminum-cad.db；
- 浏览器自动保存和工作台布局旧键继续保留。

保留项用于避免没有业务收益的迁移和本地数据丢失，并不代表对外产品名称仍为 Aluminum CAD。

## 数据与范围

- 应用版本：0.64.0；
- Project Schema：62；
- autoConnectionSystemVersion：2；
- 设计连接与制造连接分层不变；
- 不做报价、价格、商城、订单、库存、原料排料或余料。
