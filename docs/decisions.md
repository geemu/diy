- `BaseMapper.xml` 统一维护表名、完整查询字段、写入字段、公共更新片段和默认排序；业务 Mapper 通过 `<include>` 引用。

- `ACCESSORY` 是统一配件 PartType，不为端盖、脚杯、脚轮、滑轨继续增加新的 PartType。

- 配件目录对象进入 Project Part 和 BOM；连接自动派生的五金继续归入五金 BOM，用户从标准配件库添加的配件单独输出配件 BOM。
- 页面可见文案尽量中文化；视图导航使用“俯视/前视/后视/左视/右视/仰视/三维”。
- 顶部工具栏与视图导航必须遵守画布安全区，不允许互相遮挡。
- 输入框、下拉框和数字框统一 CAD 工具风格，保持清爽、克制，不引入独立前端工程。
- Project Schema 继续保持 **41**；目录、数据库和 UI 能力不因为应用版本升级而机械升级 Schema。
