# Connector System — v0.46

## 1. 目标

连接件系统负责把“两个型材看起来靠在一起”升级为可制造的业务关系：

```text
Profile A + Profile B
        ↓
Feature / Slot Match
        ↓
Connection Rule
        ↓
Connector / Fastener / Machining derivation
        ↓
Validation + Hardware BOM
```

Connection 是持久化业务对象；自动生成的五金和加工是派生结果。

## 2. 槽位模型

槽位来源于 `ProfileCatalog.slotDefinitions`：

```json
{
  "id": "LEFT-S2",
  "face": "LEFT",
  "index": 1,
  "offset": 15,
  "width": 8.2,
  "source": "CATALOG_STANDARD"
}
```

原则：
- `slotId` 在一个 ProfileDefinition 内稳定。
- `offset` 是截面局部面内坐标，不是世界坐标。
- `stationS` 是沿型材 A→B 的安装站位。
- 世界坐标只在运行时通过 Part transform 恢复。

### 当前精度边界

内置 ProfileCatalog 的槽定义是显式目录数据，但很多 SKU 仍来自标准系列几何规则。它比 v0.30 的“消费方临时近似”稳定，但不是外部来源真实 DXF 自动拓扑识别。

未来自定义 DXF/企业型材库应允许覆盖 `slotDefinitions`。

## 3. SlotMatcher

`model/SlotMatcher.js` 是连接件槽位解析唯一入口。

- `matchNearestSlot(mesh, face, pointOrOffset)`
- `slotWorldPoint(mesh, slotRef)`
- `slotWorldNormal(mesh, face)`
- `slotReference(slot)`

T 螺母、角码、锚式件、连接板不要自行计算槽中心。

## 4. Connection Rule

规则类型：

| Type | 当前用途 |
|---|---|
| END_SCREW | 端面攻丝 + 对侧孔/沉头/沉孔 |
| ANGLE_BRACKET | 外置角码 + 两腿槽紧固 |
| INTERNAL_CONNECTOR | 通用内置连接件 |
| ANCHOR_CONNECTOR | 锚式连接件 + 目标槽紧固 |
| CONNECTION_PLATE | 连接板 + 四点槽紧固 |

`ConnectionRuleCatalog.recommendConnectionRules()` 负责从系列和几何上下文给候选排序；真正能否使用仍由 `ConnectionManager.evaluateConnectionGeometry()` 决定。

## 5. 规则与派生

### END_SCREW

```text
source A/B end
  -> END_TAP

target face
  -> THROUGH_HOLE
  -> optional COUNTERSINK / COUNTERBORE

hardware
  -> SOCKET_SCREW
  -> WASHER
```

### ANGLE_BRACKET

```text
joint
  -> bracket
  -> target slot: T_NUT + WASHER + SCREW
  -> source slot: T_NUT + WASHER + SCREW
```

`sourceMountFace` 自动选择朝向目标型材内部方向的源侧面。Connection 保存 `orientationMode=AUTO_INNER`。

### INTERNAL_CONNECTOR

当前基础模型：

```text
source end -> END_TAP
joint      -> INTERNAL_CONNECTOR + screw
```

真实厂家可能要求额外孔/避让/切口，当前不自动猜。

### ANCHOR_CONNECTOR

```text
source end  -> END_TAP
joint       -> anchor connector
target slot -> T_NUT + screw
```

### CONNECTION_PLATE

生成一个标准连接板并在 source / target 各生成两组槽紧固点。Connection 保存：

```json
{
  "plateMountPattern": {
    "type": "SLOT_FASTENER_PATTERN",
    "holes": []
  }
}
```

这表示安装孔位语义，不等同于已经完成连接板自制加工图。

## 6. Generated hardware 生命周期

自动五金：
- `generatedByConnectionId` 指向 Connection。
- 不持久化到 `project.parts`。
- Connection load/rebuild 时重新生成。
- Connection 删除时必须一起删除。
- Profile transform 改变后 rebuild。

这样 project.json 不会同时保存“规则”和“规则派生副本”造成双源冲突。

## 7. mountReference

T 螺母等槽内硬件保存：

```json
{
  "slotId": "RIGHT-S1",
  "face": "RIGHT",
  "index": 0,
  "offset": -15,
  "stationS": 350,
  "width": 8.2,
  "source": "CATALOG_STANDARD"
}
```

用途：
- 生产校验。
- 五金 BOM 追溯。
- 以后装配说明和爆炸图定位。
- 以后真实槽兼容检查。

## 8. 自动推荐与 Auto Connection · v0.46

手工“智能连接”仍保留：

```text
selected profile lastSnap
  -> Editor.smartConnectRecommendedSelected()
  -> ConnectionManager.createRecommendedConnection()
  -> recommendFor()
  -> ConnectionRuleCatalog.recommendConnectionRules()
  -> evaluateConnectionGeometry() for each candidate
  -> first valid rule
```

同时新增 IdeaBuilder 风格自动连接编排层：

```text
Feature Snap / DIY generated profiles
  -> AutoConnectionResolver
  -> ConnectionManager.recommendFor()
  -> first valid rule
  -> ConnectionManager.createConnection()
  -> hardware + machining derivation
  -> BOM
```

`AutoConnectionResolver` **不拥有连接规则，也不直接生成硬件/加工**。它只决定“这个吸附关系是否应该自动建连接，以及使用哪个已经验证通过的规则”。

当前入口：

- 已有型材移动后吸附：`DRAG`；
- A/B 端 Grip 拉伸：`PROFILE_GRIP`；
- 零件库拖入：`LIBRARY_DROP`；
- 在线 LINE / POLYLINE：`PROFILE_DRAW`；
- 在线 BOX：`PROFILE_DRAW_BOX`；
- DIY 模板批量生成：`DIY_TEMPLATE`。

自动生成 Connection 会保存：

- `autoGenerated=true`；
- `autoSource`；
- `autoSnapType`；
- 推荐分数和推荐理由。

批量模式会折叠 A→B/B→A 的同一物理接头，并保证一个 source end 不自动绑定多个目标。当前仍按“一对型材一个自动物理接头”处理；复杂的同一对型材多接头留给后续专业能力。

自动连接系统版本为 `editorState.autoConnectionSystemVersion = 1`；默认开启，可在 UI 中关闭，状态持久化到 `editorState.autoConnectionEnabled`。推荐只是排序，不绕过 `ConnectionManager.evaluateConnectionGeometry()` 校验。

## 9. 五金 BOM

`BomExporter.buildHardwareBomRows()` 按 SKU 聚合数量，并附：
- 自动生成标记。
- Connection IDs。
- slotId / stationS 追溯。

Factory Package 额外输出 `五金BOM.csv`。

## 10. Factory validation

当前连接相关阻断项包括：
- 连接源/目标不存在。
- 型材路径类型不支持。
- 轴线/面法向不兼容。
- 接触间隙过大。
- 站位超出型材范围。
- 需要槽的规则未对齐目录槽。
- 型材系列不兼容。
- T 螺母与槽宽不兼容。
- 缺自动派生五金。
- T 螺母缺 `slotId` 引用。
- END_SCREW 缺攻丝/目标孔/螺钉。
