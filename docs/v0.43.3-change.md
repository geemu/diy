# v0.43.3 变更说明

## 配件目录管理

- 左侧“配件”增加“管理”入口。
- 支持新建、编辑、复制、启停、删除数据库标准配件。
- 编辑器针对端盖、脚杯、脚轮、抽屉滑轨显示中文参数，不要求直接手写 JSON。
- 保存时自动生成 `geometry_json`、`mount_rule_json`、`bom_rule_json`。

## 配件快速安装

配件卡片提供两种操作：

- **添加**：作为自由 ACCESSORY 添加到工程。
- **安装**：按照目录 `mountRule` 安装到当前选中构件，并写入 `mountReference`。

当前安装规则：

- 端盖：安装到型材端部，并校验 `profileNominal`。
- 调节脚杯：自动安装到世界坐标较低的型材端部。
- 福马轮：自动安装到世界坐标较低的型材端部。
- 抽屉滑轨：安装到所选板材侧面，滑轨长度轴与板材局部 X 轴对齐。

## Schema

Project Schema 继续为 **41**。新增字段使用当前 Schema 已允许的 ACCESSORY 扩展属性，不建立历史 migration chain。
