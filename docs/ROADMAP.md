# Product / Engineering Roadmap

产品定义：面向玩家、创客和不会 CAD 用户的浏览器铝型材 DIY Builder。设计阶段关注截面、槽、封边、长度和连接意图；制造阶段再绑定真实材料、真实五金和加工规则。

## 设计/制造边界

设计阶段：

- 截面宽高、槽位/槽宽、封边；
- 长度和空间关系；
- 抽象设计连接类型；
- 用户主动添加的设计加工需求。

制造阶段：

- 欧标/国标等真实型材规格；
- 壁厚、制造槽宽、合金；
- 真实角码/内置连接件/连接板；
- 螺钉、螺母、垫片；
- 由连接制造方案派生的最终加工参数；
- 材料/BOM/工程输出。

报价不在当前路线中。
