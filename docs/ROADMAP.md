# Product / Engineering Roadmap

产品定义：面向玩家、创客和不会 CAD 用户的浏览器铝型材 DIY Builder。设计阶段关注截面、槽、封边、长度和连接意图；制造阶段再绑定真实材料、真实五金和加工规则。

## 当前状态

v0.75.36按用户确认扩展全可见型材齐平显示：以当前主选直型材真实上向侧面为基准，不要求接触，其他实际共面的上表面变紫。保留0.1mm实际角点/法向门槛、选中橙金与干涉红色优先，底栏小图例/数量及tip说明；不改变选择或连接事实。Schema62/116模块，源码与交付文档已修改，实际浏览器效果未验收。

### 全结构齐平反馈边界（v0.75.36）

- 相对主选检查所有可见直型材，不作全体两两共面分组，也不把屏幕投影、同中心高度、已有连接或紫色当作贴合/制造有效证据。仅支持已知真实上向侧面的材料面；未知/弧形/竖直端盖不伪造平面，隐藏、其他已选与红色干涉成员不染紫。
- 新增遍历相对主选线性执行，基准平面与实际材料探测复用；原干涉分类与拖动候选没有修改。显示清理、刷新及选择变化沿原反馈链，不新增领域字段或历史。
- 待授权验收：远处后梁与主选实际齐平、不同层和倾斜排除、橙金/紫色/红色区分、多选/隐藏/撤销/几何重建的提示清理、底栏tip与密集结构观感。未新增/运行测试、Java编译、服务启动/重启或浏览器验收。

v0.75.35按用户确认改为普通单击只选一根、Shift逐个追加、Ctrl+A全选画布可见构件；不再按组件归属默选整架。输入/模态/进行中工具隔离、多选锁定/安装保护、明确组件/连接移动入口保留，Schema62/116模块。代码/交付文档已修改，实际鼠标和键盘体验尚未运行验收。

### 单选、多选与全选边界（v0.75.35）

- 全选沿用类型过滤和有效可见性，不含展示helper，不恢复隐藏件；Shift只追加、不重复，Ctrl/Meta单击可移除。普通单击可从全选/多选回到单件，不解组或改变框架参数。
- 单件选择与明确移动作用域分开；多选仍整体变换，已安装配件/锁定成员不能借全选越过编辑保护。选择本身不记历史或写草稿，原变换/连接/约束/撤销链不替换。
- 待授权验收：34根框架单件选择/移动，Shift多选/重复点击、Ctrl切换/全选/Esc、隐藏/过滤、字段与模态原生全选，拖动期间选择保护、显式整架/连接移动、锁定/安装件及保存/撤销链。未运行测试、编译、服务或浏览器验收。

v0.75.34按用户进一步要求将自动连接件简化为类型/可选规格→生成。打开和选型不先扫描，移除普通UI中的数量/范围/补侧/统计/列表/重新扫描/技术说明；点击生成后分帧扫描并自动整批提交，处理中仅短提示/取消。后台双侧、既有件保护、真实孔槽/足迹/空间和一次历史不变；Schema62/116模块。源码实现已交付，实际响应/加速与覆盖尚未测试或浏览器验收。

### 分帧生成与简洁UI边界（v0.75.34）

- UI分帧驱动与同步工具共用同一候选/空间逻辑，缓存本轮实际目录几何和主体包络，不缓存提交合法性；8ms为让出预算，不是单次几何调用或整次生成的耗时承诺。后台仍只检查当前可见直型材，未映射复杂连接件不伪装自动支持。
- 取消/关闭/新建/再开始采用任务代次保护，工程变化拒绝旧快照；确认仍新鲜重查并经原Manager原子整批提交。同步提交阶段未改成可中途打断写工程，不引入Worker、新依赖或新Schema。
- 待授权验收：初次打开只选型不扫描；单击生成、重复点击守卫、零新增简短反馈、相机/取消响应与旧任务隔离；既有C061/C062/立柱实体保护、其他合法内角、实际方向/双侧数量、一次撤销/保存刷新。没有本轮基准耗时或加速倍数。
- 原v0.75.33普通用户逐项审阅/范围配置已被本次要求覆盖，下节只保留几何能力与历史待验背景，不恢复这些控件。

## 设计/制造边界

设计阶段：

- 截面宽高、槽位/槽宽、封边；
- 长度和空间关系；
- 抽象设计连接类型；
- 用户主动添加的设计加工需求。

制造阶段：

- 欧标/国标等真实型材规格；
- 壁厚、制造槽宽、合金；
- 真实角码/内置连接件/连接板；
- 螺钉、螺母、垫片；
- 由连接制造方案派生的最终加工参数；
- 材料/BOM/工程输出。

报价不在当前路线中。
