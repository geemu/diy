# v0.54.0 变更说明

## 目标

把设计结果变成玩家看得懂、加工端可追溯的制造/装配资料：统一编号、Tagged Drawing、装配步骤和三维步骤联动。

## Schema

- 当前 Schema：54。
- current-only，不维护历史兼容。
- 新增/正式持久化 `manufacturingCode`，并加入 `manufacturingIdentityVersion=1 / assemblyInstructionVersion=1 / taggedDrawingVersion=1`。

## 统一制造编号

`ManufacturingIdentityManager` 统一分配 P/B/S/A/H/C/M/G 编号。工程保存、BOM、工程图和装配步骤全部复用该字段。

## Tagged Drawing

`EngineeringDrawingModel` 为主体构件生成编号引线；SVG/DXF 共用同一模型。默认不标自动连接派生五金，以免总装图拥挤。

## 装配步骤

- 优先使用 Assembly 安装顺序；
- 未分组时自动给出主体型材 -> 板材/功能件 -> 独立配件顺序；
- 跨步骤连接归到较晚步骤；
- 连接派生五金只在所属步骤出现一次；
- 显示前置步骤；
- 支持三维定位、步骤高亮、分步爆炸和还原。

## 制造包

新增 `BOM/装配步骤.csv` 和 `BOM/装配步骤.json`。

## 不包含

报价、单价、成本、供应商订单仍不实现。
