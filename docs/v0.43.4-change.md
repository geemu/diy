# v0.43.4 变更说明

## 配件安装关系生命周期

- 新增 `AccessoryMountManager`，`mountReference` 成为已安装标准配件的定位事实来源。
- 宿主型材/板材移动、旋转后，已安装配件自动重算世界 Transform。
- 型材 A/B 端 Grip 拉伸时，端盖、脚杯、脚轮会实时跟随新的端点。
- 板材尺寸变化或宿主几何重建后，已安装滑轨会重新贴合板材侧面。
- 工程恢复后统一执行安装关系刷新，避免保存/恢复后配件与宿主错位。
- 已安装配件不允许直接通过 Gizmo 或 XYZ/RX/RY/RZ 修改世界 Transform；需要先“解除安装”。
- 属性面板新增“解除安装”，解除后保留当前位置并恢复自由移动。
- 复制已安装 ACCESSORY 时自动清除 `mountReference`，避免副本继续错误绑定原宿主。
- 安装位置在属性面板显示为中文 A端/B端/正面/背面等。

Project Schema 继续为 41；本次只升级安装关系运行语义版本到 `accessoryMountingVersion = 2`。
