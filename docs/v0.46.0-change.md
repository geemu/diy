# v0.46.0 变更说明

## 目标

把 v0.45 的“吸附后手工点智能连接”升级为 IdeaBuilder 风格的自动连接体验，同时保持专业模式和既有制造链不变。

## 新增 AutoConnectionResolver

`static/js/connection/AutoConnectionResolver.js` 负责：

1. 读取 Feature Snap / DIY 几何候选；
2. 调用 `ConnectionManager.recommendFor()` 获取有效推荐规则；
3. 去除同一物理型材对的互反候选；
4. 避免同一源端自动建立多个目标连接；
5. 调用 `ConnectionManager.createConnection()` 创建标准 Connection；
6. 标记自动来源。

它不负责创建五金、加工或 BOM；这些继续由现有领域服务派生。

## 已接入入口

- TransformControls 移动后；
- Profile Grip A/B 端拉伸后；
- 零件库拖放；
- 在线 LINE 绘制；
- 在线 BOX 绘制；
- DIY 基础空间框 / 置物架 / 鱼缸龟缸架 / 设备机架。

## 用户控制

- 底部状态栏新增“自动连接”开关；
- DIY 模板新增“自动安装推荐连接件并同步加工 / BOM”开关；
- 连接面板对自动生成连接显示“自动”标识；
- 原有“按当前规则连接 / 自动选择连接件并连接 / 手动连接”保留。

## 数据

Project Schema 仍为 41。自动连接只给标准 Connection 增加可选字段：

```text
autoGenerated
autoSource
autoSnapType
autoRecommendationScore
autoRecommendationReasons
```

`editorState.autoConnectionSystemVersion = 1` 标记自动连接能力；`autoConnectionEnabled` 保存用户开关。

- 17 个 `tools/verify-*.mjs` 回归全部通过；
- 新增 `verify-auto-connection-v046.mjs` 覆盖单次 Snap、重复连接抑制、DIY 双向候选折叠和各入口静态契约；
