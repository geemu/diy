# v0.45.1 变更说明

本版本不修改 Project Schema，仍为 41。主要用于固化产品对标和后续开发优先级。

## 完成内容

1. 新增根目录 `IDEABUILDER_PARITY.md`。
2. 将 80/20 IdeaBuilder 确认为主要产品标杆。
3. 对齐 Click / Drag / Snap、自动硬件、快速切换紧固件、板材/脚轮、BOM、价格、设计检查、爆炸图、Tagged Drawing、装配说明和 STEP 等能力。
4. 明确采购 XML、经销商、供应商、商城和订单不属于当前项目范围。
5. 将后续版本路线重新收敛为 v0.46 ~ v0.52。
6. 明确 AI 放在领域 API 稳定之后，不允许 AI 直接操作 Three.js Scene。

## 代码影响

- 无 Project Schema 变化；
- 无数据库 Schema 变化；
- 无现有 CAD/制造功能行为变化；
- Maven 版本号提升到 `0.45.1`，作为新的开发基线。
