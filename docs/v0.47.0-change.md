# v0.47.0 变更说明

主题：IdeaBuilder 风格 Quick-change Connection / Fasteners。

- `ConnectionManager.getSwitchOptions()`：按当前接头几何列出可切换规则；不兼容方案不可选择。
- `ConnectionManager.switchConnectionRule()`：保持 Connection ID 不变，切换规则前先做几何校验；旧硬件与加工由 `rebuild()` 清理并按新规则重建。
- END_SCREW 规则切换会清除旧 M6/M8 孔径、攻丝和沉头参数，避免旧参数污染新规则。
- 切换失败自动恢复原 Connection 并重新派生旧硬件/加工。
- 自动连接经人工切换后标记 `userOverridden=true`，保留 `autoOrigin` 来源，不再视为纯自动结果。
- 右侧“连接”检查器新增连接方案下拉框和“换一个推荐方案”。
- `editorState.connectionQuickChangeVersion=1`，`connectorSystemVersion=3`；Project Schema 仍为 41。
