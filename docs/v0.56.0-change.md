# v0.56.0 变更说明

## 轮廓参数化编辑

- 新增 `ContourFrameManager`。
- 轮廓框保存原始点、工作平面、正交/网格参数和边长。
- 选中轮廓框中的型材后，右侧可直接修改每条边长度。
- “编辑轮廓点”会在三维画布显示蓝色控制点，拖动后整框重算。
- 正交锁定打开时，控制点调整保持相邻边正交。
- 自相交和小于 10mm 的短边阻止提交。

## 装配指导

- 步骤切换时相机平滑聚焦当前安装区域。
- `AssemblyInstructionGenerator` 为连接补充源/目标构件编号和本连接五金。
- 工程中心可展开 Cxxx 局部连接信息，并一键三维聚焦。

- 应用：0.56.0
