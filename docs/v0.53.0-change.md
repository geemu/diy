# v0.53.0 变更说明

## 目标

把连接、配件、加工的交互继续统一成玩家式 Builder：**移动鼠标看预览，单击才提交**。

## 配件放置

新增 `AccessoryPlacementManager`：

```text
选择配件
  -> 鼠标移到型材端部 / 板材侧面
  -> Ghost 预览
  -> 绿色：可安装
  -> 红色：不兼容 / 明显干涉
  -> 单击确认
  -> AccessoryMountManager 生成 mountReference
```

右键型材/板材进入配件库时会保留右键位置，选择配件后优先在该位置预览。

## 吸附反馈

Transform 拖动型材时，Snap Preview 会同步到 HUD：源点、目标点、绿色连接线和“即将吸附”提示。松手后才真正改变位置并触发自动连接。

## 工作台

顶部菜单从 5 个收敛为 4 个：

```text
文件 / 设计 / 制造 / 更多
```

视图与帮助进入“更多”；常用视图仍由画布视图导航直接提供。

## 数据边界

- Project Schema 仍为 50。
- `mountReference` 仍是配件安装关系的业务事实。
- Placement Manager 不新增第二套配件模型。
- 报价、单价、成本估算继续暂缓。
