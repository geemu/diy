# v0.55.0 变更说明

## 目标

继续沿着“玩家型材 Builder”而不是通用 CAD 的方向，补齐两项高价值能力：

1. 任意闭合轮廓快速生成型材框架；
2. 装配步骤从静态清单升级为可播放的分步装配演示。

## 轮廓生成框架

`ProfileDrawTool` 新增 `CONTOUR` 模式。

- 在当前工作平面依次点击轮廓转折点；
- 至少 3 个点；
- 点击第一个点附近或点击“完成闭合并生成”即可闭合；
- 生成前检查短边和自相交；
- 每条轮廓边生成标准 `PROFILE`；
- 全部边归入同一个 Assembly；
- 开启自动连接时继续委托 `AutoConnectionResolver / ConnectionManager` 建立设计连接；
- 生成结果不是特殊 Mesh，后续替换型材、制造配置、BOM、工程图继续使用现有链路。

## 装配播放

新增 `manufacturing/AssemblyPlaybackManager.js`。

- 使用 `AssemblyInstructionGenerator` 的现有步骤作为唯一数据来源；
- 未安装的后续构件在播放时隐藏；
- 当前步骤构件从爆炸位置动画回真实安装位置；
- 支持播放、暂停、上一步、下一步、单步播放和退出预览；
- 播放只改变场景展示状态，不修改真实 Part transform，不写回 Project JSON；
- 当前步骤仍使用统一 P/B/S/A/H/C/M/G 制造编号。

## Schema

- 应用版本：`0.55.0`
- Project Schema：`55`
- current-only，不提供旧 Schema migration。
- `editorState.contourFrameVersion = 1`
- `editorState.assemblyPlaybackVersion = 1`

## 明确不做

- 报价、单价、成本估算；
- STEP 在本版仍未进入实现范围；
- 不引入通用 B-Rep / Sketcher 作为轮廓功能基础。
