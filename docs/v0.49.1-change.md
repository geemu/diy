# v0.49.1 变更说明

## 目标

把产品从“设计时直接绑定真实材料 SKU 的 CAD”调整为“玩家先搭结构，制造信息后置”的 DIY Builder，并修正角码/加工难以手动放置的问题。

## 主要变更

### Schema 49 / current-only

- `CURRENT_PROJECT_SCHEMA_VERSION = 49`；
- 只接受当前 Schema；
- 不迁移旧工程，不兼容旧 `profileSpec`。

### DesignProfile

新增 `DesignProfileCatalog.js`。设计目录只包含截面尺寸、系列、槽宽、槽位和封边语义。PROFILE 新建时写入 `designProfile`，并保持 `manufacturingProfile=null`。

### 封边

`ProfileFeatureCatalog` 在解析槽位时检查 `designProfile.faceClosures`。封闭面不再返回槽中心 Anchor。

### 玩家式连接放置

新增/强化 `ConnectionPlacementManager`：

- 选择角码/内置/连接板/锚式后进入连接放置；
- hover 只显示 Anchor/Ghost；
- 单击接头优先解析唯一的 `source PROFILE_END + target PROFILE_FACE/SLOT`；
- 解析不唯一时退回两次点击；
- 实际 Connection 继续通过 `ConnectionManager` 创建。

新增 `resolveProfileSurfaceFeature()`，专门解析侧面/槽位，避免靠近目标 A/B 端时被 `PROFILE_END` 抢占。

### 玩家式加工放置

`MachiningPlacementManager` 支持在真实点击位置添加通孔、沉头孔、槽、端面攻丝和端面孔。hover 显示 Ghost，点击才写入 `MachiningFeature`。

### 中文工作台 / 简易模式

- 默认 `BEGINNER`；
- 左侧提供型材、连接、板材、配件、加工、检查；
- 专业约束和高级编辑只在专业模式显示；
- 顶部菜单一次只打开一个，点击空白和执行动作后自动收起；
- 用户直接可见文案优先中文，不展示内部英文状态名。

## 暂不实现

- 报价、单价、成本估算；
- 供应商价格体系；
- 历史 Project Schema 兼容。

## 下一步

v0.50 进入制造配置中心：DesignProfile 映射真实 ManufacturingProfile，并在材料查看/导出时选择欧标/国标、壁厚、米重以及实际连接/加工方案；不做报价。
