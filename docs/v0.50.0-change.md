# v0.50.0 变更说明

## 目标

把 v0.49.1 的“设计型材 / 制造型材分离”扩展到连接领域，并增加独立制造配置中心。玩家继续在简洁设计工作台里搭结构；真实材料、真实角码/紧固件以及连接派生加工只在制造阶段确定。

## Schema 50

当前版本只接受 Schema 50，不兼容历史工程。

PROFILE：

```text
designProfile.profileId   必填
manufacturingProfile       设计阶段 null，制造配置后绑定真实目录规格
```

Connection：

```text
designType                 必填，表达设计连接意图
manufacturingRuleId         设计阶段 null，制造配置后绑定真实连接规则
```

## 制造配置中心

页面分为：

- 型材材料；
- 连接与加工；
- 完成情况。

支持同一设计截面批量选择真实制造型材、一键推荐、清空配置以及配置完成状态统计。

## 真实连接与加工

设计阶段创建 Connection 时不生成真实螺钉、T 螺母和连接派生加工。制造配置绑定 `manufacturingRuleId` 后，`ConnectionManager.rebuild()` 才生成真实五金和加工。

制造连接依赖两端真实型材：材料未配置时连接制造方案禁用；T 螺母按真实制造槽宽校验。材料变更导致当前方案不兼容时，会清除该制造规则并回到待配置。

## 制造导出门禁

正式制造包导出前检查：

1. 所有设计型材已映射真实制造型材；
2. 所有设计连接已配置真实制造规则；
3. `FactoryValidator` 生产检查通过。

未完成时直接打开制造配置，不生成误导性的“完整”制造包。

## BOM

型材分组键包含真实 `manufacturingProfile.profileId`；材料清单同时显示设计截面与真实制造规格，未配置时显示“待配置”。

## 范围

本版不包含：报价、单价、成本估算、供应商订单、库存、原料排料。

## 工作台中文化收口

- 制造与工程图页面不再显示 `Warning / Error / Drawing Model / Feature / mountReference / DATABASE_CUSTOM` 等内部词；
- 工程图导出入口统一为“导出 SVG / 导出 DXF 制图文件”；
- 加工面板用户名称统一为“加工项”；
- 配件安装关联、截面高级数据等内部字段改为中文业务描述；
- 工程图标题栏统一显示“铝型材设计器”。

文件格式名 SVG / DXF、尺寸单位 mm 以及坐标轴 X/Y/Z 属于必要工程符号，继续保留。
