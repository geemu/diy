# v0.61.0 变更说明

- 应用版本：0.61.0
- Project Schema：60
- 策略：current-only，不维护历史工程兼容。

## 接头附近快捷菜单

- `ConnectionPlacementManager.resolveJointContext()` 从鼠标命中的型材和世界坐标直接解析当前物理接头，不依赖当前是否已经选择连接工具。
- 悬浮和右键菜单只展示 `ConnectionManager.recommendDesignFor()` 对当前源端 / 目标面判定为可用的设计连接。
- 选择候选后优先直接在当前接头安装；解析存在歧义或无法直接安装时，回退到原有两点选择链。
- 开放型材端部可显示与当前设计截面匹配的端盖；选择后进入现有配件 Ghost 预览并由用户单击确认。

## 轮廓关系快捷修改

- 点击画布上的 `＝ / ∥ / 横 / 纵` 打开中文浮动编辑卡。
- 等长/平行可直接修改两条边，横/纵对齐可直接修改两个点及方向。
- 支持“应用调整 / 切换关系 / 删除关系”。
- 所有操作继续复用 `Assembly.parameters.simpleConstraints`；需要改变轮廓时修改 `parameters.points` 后整框重建，与右侧属性自然同步。

## Cxxx 装配说明局部放大

- 装配步骤把 Connection 的 `sourceEnd / targetFace / sourceMountFace / placement` 一并传入展示层。
- `ConnectionInstallationDiagram` 同卡展示当前 Cxxx 接头局部放大、二维安装方向、安装步骤和本接头五金。
- 阅读模式与打印模式消费同一 SVG，不保存第二份装配说明业务数据。

## 明确不做

- 不做报价、单价、成本估算。
- 不做旧 Schema 或旧工程迁移。
- 不改变“设计型材只关心截面/槽/封边；真实标准与材料属性后置到制造配置”的既有边界。
