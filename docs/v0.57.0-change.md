# v0.57.0 变更说明

## 版本

- 应用：0.57.0
- Project Schema：57
- current-only，不维护旧工程迁移。

## 轮廓直接编辑

- 编辑模式显示可点击边长标签。
- 点击尺寸标签直接输入边长。
- 右键轮廓边可在点击位置插入转折点。
- 右键蓝色控制点可删除；至少保留 3 点，正交轮廓删除后不得产生斜边。
- 正交边长修改会传播相邻点位移，保持闭合轮廓拓扑。

## 快捷轮廓

新增 L 型、U 型、阶梯型模板。模板只生成轮廓点并调用标准 `createContourFrame()`，最终仍是 PROFILE + Assembly + Auto Connection。

## 连接安装示意

装配步骤中的 Cxxx 连接增加二维 SVG 安装示意，显示连接类型、两端构件编号和当前连接五金；三维聚焦继续复用现有连接数据。

## 范围

报价、单价、成本估算仍不实现。
