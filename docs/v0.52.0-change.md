# v0.53.0 变更说明

## 目标

优先改善“搭建时看不出是否吸附、放上去才发现穿模、右键不知道下一步做什么、菜单层级太散”的问题。

## 已完成

1. **实时干涉反馈**
   - Transform 拖动过程中实时检查当前移动构件与其他物理构件。
   - PROFILE×PROFILE 使用 OBB SAT；其余使用快速世界包围盒。
   - 干涉构件显示红色包围线，画布显示干涉 HUD；落位后持续显示直到问题解除。
   - 连接派生五金与 mountReference 配件不作为干涉处理；PROFILE 间正常端面贴合由碰撞容差自然放行，真实穿透仍提示。

2. **吸附可视化**
   - `SnapManager.preview()` 在拖动中计算最佳候选但不改坐标。
   - 画布显示绿色源点、目标点和连接线；松手后执行真实 Snap/Auto Connection。

3. **右键上下文菜单**
   - 型材：角码、内置连接、连接板、配件、加工、板材/门、长度等。
   - 板材：配件、板材/门、属性。
   - 配件：属性、解除安装关系。
   - 从型材端部右键启动连接时预选当前端部；右键端部后安装端盖等配件时复用该端部。

4. **工作台收敛**
   - 顶部一级菜单从 8 个收敛为 5 个：文件 / 设计 / 视图 / 制造 / 帮助。
   - 左侧竖栏只保留主要设计域；移动/旋转/复制/选择等继续使用画布浮动工具条。
   - 样式统一右键菜单、干涉 HUD、吸附提示和工具栏选中状态。

## 数据边界

- Project Schema 保持 50。
- 不做历史工程兼容。
- 干涉反馈和 UI 菜单布局不进入业务 Project JSON。
- 报价、价格、供应商订单仍不做。
