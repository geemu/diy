# v0.43.5 变更说明

本版本只调整 CAD 编辑器交互文案和解释性提示，不修改 Project Schema 或领域数据结构。

## 中文交互术语

- `套索` → **自由选择**：按住左键绘制不规则区域选择构件，快捷键仍为 `L`。
- `成组` → **组合组件**：把多个构件组织到同一组件中，不合并几何实体，快捷键仍为 `Ctrl+G`。
- `取消分组` → **取消组合**。
- `镜像` → **镜像复制**：按镜像平面生成对称构件；原有“原地镜像”模式继续保留。
- `建子装配` → **创建子装配**：把多个已有组件组织到新的上级装配层级。

## 不变项

- Project Schema：41。
- 快捷键和底层 Editor / AssemblyManager API 不变。
- MySQL / MyBatis、Accessory Catalog、配件安装关系均不变。
