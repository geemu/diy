# v0.51.0 变更说明

## 工作台布局

- 左侧设计工具、右侧属性面板默认停靠。
- 拖动面板顶部“拖动浮动”区域后切换为浮动窗口。
- 双击面板拖动区或点击“停靠”恢复原侧边位置。
- 面板边缘可拖动调整宽度；浮动面板继续使用可视区域高度限制。
- 顶部三维工具条和视图导航均可拖动；双击拖动手柄恢复默认位置。
- 视图菜单新增“复位工作台布局”。
- 所有布局位置使用 localStorage 保存，不写入 Project JSON。
- 布局改变会主动触发 resize，让 Three.js 渲染区域立即更新。

## 工程中心

- 材料、配件、加工清单仍从当前 Project 实时计算。
- 双击包含 P-/S-/B-/A- 构件编号的清单行，会关闭工程中心、选中对应三维构件并适配视图。
- 三维画布中已有选择时打开工程中心，对应清单行会自动高亮并滚动到可视区域。

## 数据

- Project Schema 仍为 50。
- 应用版本升级为 0.51.0。
- 不做历史兼容。
- 不包含报价、单价或成本估算。
