# v0.63.0 变更说明

本版目标只有一个：先把铝型材 DIY 的基础编辑做得可预期。

## 1. 拖动与移动作用域

- TransformControls 平移支持自由 / 1 / 5 / 10 / 50 mm 步长。
- 拖动时顶部 HUD 实时显示 X/Y/Z 位移或旋转角度。
- 型材右键可切换“单个移动 / 保持连接移动 / 移动整个装配”。
- 保持连接移动通过现有 `connections[]` 做 BFS，不新增关系模型。

## 2. 吸附

- 端面、槽中心、端点按优先级排序。
- 当前候选使用锁定/释放距离形成滞回，避免鼠标轻微移动时候选来回跳。
- Ctrl 临时关闭几何吸附；松开恢复。
- 移动组内其他型材不参与当前吸附候选。

## 3. 红/绿几何反馈

- 绿色：几何吸附或合法近面接触。
- 红色：PROFILE OBB 真实体积穿透。
- 红色落位会自动恢复拖动前完整快照并提示原因，不写入 History。
- 绘制新型材时也会预判干涉；预览线在穿透时转红。

## 4. 连续搭框

- POLYLINE 后一根型材从前一根型材侧面开始，避免中心线角点直接重叠。
- RECTANGLE / CONTOUR 保存原始逻辑轮廓点，但派生 PROFILE 段按下一边截面半宽修剪。
- `ContourFrameManager` 重建时使用同一规则，后续修改轮廓不会重新产生角部假干涉。
- 连续/轮廓绘制在确定起点后可直接键入长度并回车提交，不必再去左侧填写固定长度。
- 连续绘制支持退格撤回上一根刚创建的型材，同时清理该段自动连接/约束；Esc 直接结束连续绘制。
- Ctrl 临时关闭几何吸附时，绘制工具也真正绕过端点/端面/槽位和网格吸附；Shift 可临时强制正交锁轴。
- RECTANGLE / CONTOUR / BOX 在提交前统一做实体干涉检查；红色方案不会写入工程。

## 5. 菜单

- 顶部一级入口：文件 / 编辑 / 视图 / 显示 / 移动步长（吸附） / 模型库 / 制造。
- 右键菜单、接头菜单、关系菜单均按实际 DOM 尺寸做 viewport clamp。
- 页面底部/右侧右键时，菜单自动向上/向左避让并允许内部滚动。
- 移动、复制、聚焦、删除位于右键菜单第一屏。
- 空白画布右键不再复用旧选择对象菜单，直接给出直线/连续/矩形绘制与视图入口。
- 型材右键可直接输入总长度，并明确选择“A 端固定，调整 B 端”或“B 端固定，调整 A 端”，不再依赖浏览器 `prompt`。
- `SINGLE` 单个移动后若原 Cxxx 已因几何分离变成 INVALID，会自动解除该失效连接；需要整体保持时使用“保持连接移动”。
